## A reference project with an executive review path

**[Agent Governance Kit](https://github.com/haxforscience-eng/agent-governance-kit)** makes proposed agent actions inspectable through explicit mandates, independent approvals, execution controls and evidence.

Start with the [executive brief](https://github.com/haxforscience-eng/agent-governance-kit/blob/main/docs/EXECUTIVE-BRIEF.md), then review the [operating model](https://github.com/haxforscience-eng/agent-governance-kit/blob/main/docs/OPERATING-MODEL.md) and [threat model](https://github.com/haxforscience-eng/agent-governance-kit/blob/main/docs/THREAT-MODEL.md). The working Python implementation includes tests for approval tampering, replay, budget reservations, emergency stops and concurrent execution.

Nine synthetic scenarios demonstrate three completed fixture executions and six blocked actions. The reference is an educational control implementation with explicit integration requirements; it makes no production assurance or certification claim.

## Leadership perspectives

- **Information security:** translate risk into accountable choices, decision rights and evidence.
- **Cloud security:** make identity, delegated authority and trust boundaries explicit.
- **AI governance:** define purpose, bounded permissions, independent review and operational intervention before scaling autonomy.
